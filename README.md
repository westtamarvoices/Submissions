# West Tamar Submission Helper

A free, independent volunteer tool that helps West Tamar residents write their own submissions to West Tamar Council, including representations on planning applications, letters to councillors and questions for public question time.

Residents choose an issue, add their own points and details, and the page builds a draft they can edit and send themselves. Everything happens in the visitor's own browser. Nothing they type is stored or sent anywhere by this site.

This tool is not affiliated with or endorsed by West Tamar Council.
